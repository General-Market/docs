# Cookie Banner

## Headline

Cookies, briefly.

## Body

The website uses cookies. Three categories, no euphemism.

**Essential** — the things that make the site work. Wallet connection, session, route. These run no matter what you click.

**Preferences** — your theme, your last-used board, the gate you have already affirmed. We keep them so the site stops asking you the same questions every visit.

**Analytics** — PostHog. Aggregated traffic, page views, error rates. Used to see what is broken. Off if you reject.

The chain knows what your wallet does. The website knows almost nothing else. Read the [Cookie Policy](/legal/cookie-policy) for the full list and the retention windows.

## Buttons

- **Accept** — all three categories.
- **Reject** — essential only.
- **Customize** — pick per-category.
