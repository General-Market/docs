## How to identify fraud

Today, every claim about the nsgame token is fraudulent — because there is no token. Concretely:

- **No sale.** There is no public sale, presale, private round, OTC desk, or whitelist. Anyone selling you nsgame tokens is selling you nothing.
- **No airdrop.** There is no claim portal, no eligibility checker, no signature-required wallet drainer dressed up as an airdrop. If a site asks you to "verify your wallet" to claim nsgame tokens, it is asking you to sign a transaction that empties it.
- **No CEX listing.** There is no listing on any centralized exchange. Tickers that look like nsgame on CEXs are not nsgame.
- **No DEX pool.** There is no liquidity pool on any DEX. Tokens with our name on Solana, Ethereum, BNB Chain, or anywhere else are not nsgame.
- **No partner announcement.** No "X partnered with nsgame" announcement is real before nsgame.org publishes one.

The simplest filter: if it is not announced on nsgame.org, it is not nsgame.

If someone offers you the nsgame token, ignore them. If a site claims to host an nsgame airdrop, close the tab. If a wallet pop-up asks you to sign for an nsgame claim, reject it. The protocol is on devnet. The token is in the future. The scammers are in the present, and they are inventive.

When the token is real, this page will say so. Until then, this page says no.
