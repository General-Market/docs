General Market is a protocol for on-chain index funds, prediction markets, and DeFi lending. It runs on a custom Arbitrum Orbit L3 (a Layer 3 chain settling to Arbitrum) with sub-second finality and near-zero gas.

**Key facts**

- **3 product pillars** — Index (DTFs), Vision (prediction markets), Lending (Morpho-powered)
- **8 services + 29 smart contracts** across 2 EVM chains
- **90+ real-world data sources** — crypto, weather, transport, energy, GitHub, sports, and more
- **BLS consensus on everything** — index trades, prediction resolutions, bridge relays
- **Sealed parimutuel bets** — no front-running, no house edge beyond a 0.05% fee

Jump in: [Getting Started](/index/getting-started) (~5 min).

## The Three Pillars

<CardGroup cols={3}>
  <Card title="Index (DTFs)" icon="chart-pie" href="/index/concepts/itps">
    Baskets of up to 100 crypto assets. Each Dex Traded Fund (DTF) is an ERC-4626 vault priced by a NAV (Net Asset Value) formula. Orders pass through BLS consensus and execute on real exchanges — no AMM, no slippage from virtual liquidity.
  </Card>
  <Card title="Vision" icon="eye" href="/vision/introduction">
    Prediction markets on 90+ real-world data sources — transport delays, power outages, weather, GitHub commits, energy prices. Sealed bets, parimutuel payouts (winners split losers' stakes), BLS-verified resolution.
  </Card>
  <Card title="Lending" icon="building-columns" href="/index/concepts/lending">
    Morpho-powered lending on Arbitrum. Deposit USDC to earn yield. Use DTF shares as collateral to borrow USDC against positions you want to keep.
  </Card>
</CardGroup>

## The Infrastructure Beneath

Five backing services keep the three product pillars running.

<CardGroup cols={2}>
  <Card title="Data Node" icon="database">
    Rust service that feeds every other component. Aggregates 90+ data sources (crypto, transport, energy, weather, GitHub) into one API. Drives NAV computation, market resolution, backtesting, and anomaly detection.
  </Card>
  <Card title="Bridge" icon="bridge">
    Moves assets between Index L3 and Arbitrum. DTF shares cross as standard ERC-20 tokens, composable with Arbitrum DeFi on the other side.
  </Card>
  <Card title="Explorer" icon="magnifying-glass-chart">
    System health dashboard — oracle node status, consensus metrics, data source monitoring, fee tracking.
  </Card>
  <Card title="Bot Framework" icon="robot">
    Python trading bots for Vision markets. Register on-chain through `BotRegistry`. Build strategies programmatically. See the [Python example bot](/docs/blocks/examples).
  </Card>
  <Card title="Social Bot" icon="bullhorn">
    Anomaly detector across 90+ sources. Posts to Twitter/X when an unusual reading lands — transit collapse, grid failure, weather event.
  </Card>
</CardGroup>

## Convictions

Four design choices that shape the whole protocol.

<CardGroup cols={2}>
  <Card title="BLS consensus on everything">
    Every ITP trade, every Vision tick resolution, every bridge relay carries a multi-party BLS signature. No test modes, no owner overrides, no bypass flags.
  </Card>
  <Card title="Real exchange execution">
    ITP orders execute on Bitget through Authorized Participants. No AMM pools. No virtual liquidity. Real order books.
  </Card>
  <Card title="Sealed parimutuel betting">
    Vision bets stay sealed until resolution. Parimutuel payout: winners split the pool proportionally minus 0.05% fee.
  </Card>
  <Card title="90+ real-world data sources">
    Not just crypto. Transport delays across 4 countries, power outages, weather stations, GitHub repos, energy grids, sports.
  </Card>
</CardGroup>
