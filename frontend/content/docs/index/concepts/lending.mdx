# Lending and Borrowing

You deposit USDC to earn yield, or deposit DTF (Dex Traded Fund) tokens as collateral to borrow USDC. Both sides run on Morpho, a DeFi lending protocol with isolated markets per DTF.

- Lenders deposit USDC, earn variable interest, withdraw anytime
- Borrowers deposit DTF tokens, draw USDC up to the market's loan-to-value (LTV) ratio
- Each DTF market is isolated — risk does not spill across DTFs
- Health factor below 1.0 triggers liquidation

## Quick Start: Earn Yield on USDC

1. Go to the **Lending** section on [generalmarket.io](https://generalmarket.io) (~1 min)
2. Pick a lending market (each corresponds to a DTF)
3. Deposit USDC — interest begins immediately
4. Withdraw anytime, subject to available liquidity

## How It Works

```
  +------------+                                      +------------+
  |            |         +------------------+         |            |
  |   LENDER   | ------> |                  | <------ |  BORROWER  |
  |            | deposit |   MORPHO MARKET   | deposit |            |
  |  Deposits  |  USDC   |                  |  ITP    |  Deposits  |
  |  USDC      |         |  Matches lenders |  shares |  ITP as    |
  |            |         |  with borrowers  |         |  collateral|
  |  Earns     | <------ |                  | ------> |  Borrows   |
  |  interest  | yield   |  Isolated risk   |  USDC   |  USDC      |
  |            |         |  per ITP market  |         |            |
  +------------+         +------------------+         +------------+
                              |        ^
                              |        |
                         interest   repay +
                         accrues    interest
```

<Info>
Not every DTF has a lending market — only those configured with a Morpho market. Check the DTF detail page.
</Info>

## How Morpho Lending Works

Lending runs on [Morpho](https://morpho.org/) (~2 min). Each DTF gets its own isolated market with its own parameters. A collapse in one basket does not threaten another.

Two roles per market:

| Role | What You Do | What You Earn/Pay |
|------|-------------|-------------------|
| **Lender** | Deposit USDC into the lending pool | Earn interest from borrowers |
| **Borrower** | Deposit DTF tokens as collateral, borrow USDC | Pay interest to lenders |

## Supplying USDC (Lending)

You deposit USDC. Someone else borrows it. They pay you interest.

### How to Supply

1. Navigate to the **Lending** section.
2. Select a lending market.
3. Enter the USDC amount.
4. Approve and confirm.

### Key Details

- **Yield** — variable interest paid by borrowers; the rate adjusts with utilization
- **Withdraw anytime** — subject to available liquidity. If utilization is 100%, withdrawals wait until repayments arrive
- **No lock-up** — no minimum deposit period

<Tip>
Lending earns USDC yield without DTF price exposure. Principal stays in USDC, interest accrues, basket movements do not touch you.
</Tip>

## Borrowing Against DTFs

You hold DTF tokens, want USDC, do not want to sell. Morpho lets you borrow against the position.

### How to Borrow

1. Navigate to the **Lending** section and select the market for your DTF.
2. **Deposit collateral** — transfer DTF tokens into the Morpho market.
3. **Borrow USDC** — draw up to the allowed loan-to-value (LTV) ratio.
4. Use the USDC anywhere.

### Health Factor

Health factor is a single number that measures how close your position is to liquidation. Watch it closely.

```
  Health Factor = (Collateral Value * LLTV) / Debt

  Where:
  - Collateral Value = ITP shares * NAV oracle price
  - LLTV = Liquidation Loan-To-Value (e.g., 77%)
  - Debt = borrowed USDC + accrued interest
```

```
  HEALTH FACTOR SCALE
  ====================

    0.0         1.0         1.5         2.0         3.0+
     |           |           |           |           |
     +-----------+-----------+-----------+-----------+---->
     |XXXXXXXXXXX|           |           |           |
     | LIQUIDAT- |  CAUTION  | MODERATE  |   SAFE    |
     |   ABLE    |  Monitor  |           |           |
     |XXXXXXXXXXX|  closely  |           |           |
     +-----------+-----------+-----------+-----------+
                 ^
                 |
          Liquidation threshold
```

| Health Factor | Status |
|---------------|--------|
| > 1.5 | Safe — comfortable margin |
| 1.0 - 1.5 | Caution — monitor closely |
| ≤ 1.0 | Liquidatable — collateral can be seized |

<Warning>
At **1.0 or below**, the position is liquidatable. A liquidator repays part of your debt and takes your collateral at a discount. Monitor the health factor, especially during volatility — the protocol does not warn you. The number *is* the warning.
</Warning>

### What Moves the Number

```
  DECREASES (dangerous)              INCREASES (safer)
  =====================              ==================

  +-------------------------+        +-------------------------+
  | ITP NAV drops           |        | ITP NAV rises           |
  | (assets in basket fall) |        | (assets in basket rise) |
  +-------------------------+        +-------------------------+
  | Interest accrues        |        | Borrower repays debt    |
  | (debt grows over time)  |        | (debt decreases)        |
  +-------------------------+        +-------------------------+
  | Borrower withdraws     |        | Borrower deposits more  |
  | collateral              |        | collateral              |
  +-------------------------+        +-------------------------+
```

Two ways to raise the health factor:

- **Deposit more collateral** — add more DTF tokens
- **Repay debt** — return USDC, reduce what you owe

## Liquidation

When the health factor touches 1.0, anyone can liquidate the position. Liquidation is permissionless and partial — enough to restore HF above 1.0, no more.

```
  LIQUIDATION FLOW
  ================

  +----------------+                     +------------------+
  |   Liquidator   |     liquidate()     |   Morpho Blue    |
  |                | ------------------> |                  |
  |  Repays $X of  |   (borrower addr,   |  1. Check HF<1   |
  |  borrower's    |    amount, data)    |  2. Compute ITP  |
  |  USDC debt     |                     |     to seize     |
  |                |                     |  3. Add bonus    |
  |  Receives ITP  | <------------------ |  4. Transfer     |
  |  collateral    |   ITP + bonus       |                  |
  |  at discount   |                     +--------+---------+
  +----------------+                              |
                                                  v
                                         +--------+---------+
                                         |   Borrower's     |
                                         |   Position       |
                                         |                  |
                                         |  collateral -= X |
                                         |  debt -= Y       |
                                         |  HF improves     |
                                         +------------------+
```

### How It Works

1. A liquidator repays part of your USDC debt.
2. They take an equivalent value of your DTF collateral, plus a **liquidation bonus** (a discount on what they seize).
3. You keep whatever remains.

### Key Properties

- **Partial, not full** — only enough collateral is seized to restore HF above 1.0
- **Permissionless** — any address can call `liquidate()`
- **Liquidation bonus** — collateral seized at a discount; this is the incentive for liquidators
- **No grace period** — HF drops below 1.0, liquidation is immediate
- **Oracle-dependent** — health factor uses the ITPNAVOracle. If the oracle is stale, `price()` reverts and liquidation is blocked

```
  PARTIAL LIQUIDATION EXAMPLE
  ============================

  BEFORE                           AFTER
  ======                           =====
  Collateral: 10,000 ITP           Collateral: 7,900 ITP
  Debt:       $8,000 USDC          Debt:       $6,000 USDC
  HF:         0.96                 HF:         1.01

              Liquidator
              repays $2,000 USDC
              receives 2,100 ITP
              (5% bonus)
```

<Note>
Partial liquidation restores health without wiping the borrower out.
</Note>

## Risks

| Risk | Description | Mitigation |
|------|-------------|------------|
| **Liquidation** | DTF NAV drops, health factor falls below 1.0 | Keep health factor above 1.5; set up monitoring alerts |
| **Utilization** | High borrowing utilization blocks immediate lender withdrawals | Liquidity returns as rates rise and attract repayments |
| **Smart contract** | Morpho or DTF contract vulnerabilities | Morpho is well-audited; DTF contracts are audited |
| **Oracle** | Price feed delays or inaccuracies | NAV is computed from multiple price sources with validation |

## Example: Leveraged DTF Position

A 1.5x leveraged loop, end-to-end:

```
  STEP-BY-STEP LEVERAGE
  =====================

  1. Buy $10,000 of T100 ITP
     +----------+    buy     +---------+
     | $10,000  | ---------> | 10,000  |
     |  USDC    |            | T100 ITP|
     +----------+            +---------+

  2. Deposit ITP as collateral
     +---------+   deposit   +------------------+
     | 10,000  | ----------> | Morpho Market    |
     | T100 ITP|             | collateral=10,000|
     +---------+             +------------------+

  3. Borrow $5,000 USDC (50% LTV)
     +------------------+   borrow   +----------+
     | Morpho Market    | ---------> | $5,000   |
     | debt = $5,000    |            | USDC     |
     | HF = 1.54        |            +----------+
     +------------------+

  4. Buy more ITP with borrowed USDC
     +----------+    buy     +---------+
     | $5,000   | ---------> |  5,000  |
     |  USDC    |            | T100 ITP|
     +----------+            +---------+

  RESULT:
  +------------------------------------------+
  | Capital invested:  $10,000               |
  | ITP exposure:      $15,000 (1.5x lever.) |
  | Debt:              $5,000 USDC           |
  | Health Factor:     1.54                  |
  +------------------------------------------+

  If ITP +10%: portfolio = $16,500, profit = $1,500 (15% on capital)
  If ITP -10%: portfolio = $13,500, loss   = $1,500 (15% on capital)
```

<Warning>
Leverage amplifies both directions. A 10% NAV decline at 1.5x becomes a 15% loss on capital. The math is symmetric. Size positions accordingly.
</Warning>
