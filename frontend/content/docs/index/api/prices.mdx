# Price Endpoints

Four endpoints, ranked by freshness vs latency.

| Endpoint | Use for |
|---|---|
| `/price` | Single asset, most current |
| `/prices` | All assets, array form |
| `/latest-prices` | All assets, map keyed by ticker |
| `/fast-prices` | Cached, UI display, may lag a few seconds |

---

## Get Single Asset Price

Returns the latest USD price for one ticker, with source and timestamp.

<ParamField query="asset" type="string" required>
  Asset ticker symbol (e.g., `BTC`, `ETH`, `SOL`).
</ParamField>

<CodeGroup>
```bash cURL
curl "https://generalmarket.io/api/price?asset=BTC"
```

```javascript JavaScript
const res = await fetch("https://generalmarket.io/api/price?asset=BTC");
const data = await res.json();
```

```python Python
import requests

resp = requests.get("https://generalmarket.io/api/price", params={"asset": "BTC"})
data = resp.json()
```
</CodeGroup>

<Expandable title="Response">
```json
{
  "asset": "BTC",
  "price": 97432.15,
  "timestamp": 1708600000,
  "source": "binance"
}
```
</Expandable>

| Field | Type | Description |
|-------|------|-------------|
| `asset` | string | Asset ticker symbol |
| `price` | number | Latest price in USD |
| `timestamp` | number | Unix timestamp of the price update |
| `source` | string | Data source that provided the price |

Need every asset at once? See [Get All Latest Prices](#get-all-latest-prices).

## Get All Latest Prices

Returns every supported asset as an array of `{asset, price}` objects.

<CodeGroup>
```bash cURL
curl "https://generalmarket.io/api/prices"
```

```javascript JavaScript
const res = await fetch("https://generalmarket.io/api/prices");
const data = await res.json();
```

```python Python
import requests

resp = requests.get("https://generalmarket.io/api/prices")
data = resp.json()
```
</CodeGroup>

<Expandable title="Response">
```json
[
  { "asset": "BTC", "price": 97432.15 },
  { "asset": "ETH", "price": 3245.80 },
  { "asset": "SOL", "price": 187.42 },
  { "asset": "AVAX", "price": 38.15 }
]
```
</Expandable>

| Field | Type | Description |
|-------|------|-------------|
| `asset` | string | Asset ticker symbol |
| `price` | number | Latest price in USD |

Prefer a ticker-keyed map? See [Get Latest Prices (Bulk Map)](#get-latest-prices-bulk-map).

## Get Latest Prices (Bulk Map)

Returns the same data as `/prices`, keyed by ticker for direct lookup.

<CodeGroup>
```bash cURL
curl "https://generalmarket.io/api/latest-prices"
```

```javascript JavaScript
const res = await fetch("https://generalmarket.io/api/latest-prices");
const priceMap = await res.json();
console.log(priceMap["BTC"]); // 97432.15
```

```python Python
import requests

resp = requests.get("https://generalmarket.io/api/latest-prices")
price_map = resp.json()
print(price_map["BTC"])  # 97432.15
```
</CodeGroup>

<Expandable title="Response">
```json
{
  "BTC": 97432.15,
  "ETH": 3245.80,
  "SOL": 187.42,
  "AVAX": 38.15,
  "LINK": 19.22
}
```
</Expandable>

Keys are tickers. Values are USD prices.

For lower latency at the cost of freshness, see [Get Fast Prices](#get-fast-prices).

## Get Fast Prices

Returns cached USD prices for every supported asset. May lag real-time by a few seconds. Use for UI display and order previews — not final execution pricing.

<CodeGroup>
```bash cURL
curl "https://generalmarket.io/api/fast-prices"
```

```javascript JavaScript
const res = await fetch("https://generalmarket.io/api/fast-prices");
const prices = await res.json();
```

```python Python
import requests

resp = requests.get("https://generalmarket.io/api/fast-prices")
prices = resp.json()
```
</CodeGroup>

<Expandable title="Response">
```json
{
  "BTC": 97432.15,
  "ETH": 3245.80,
  "SOL": 187.42,
  "AVAX": 38.15
}
```
</Expandable>

<Note>
  Fast prices are cached and may lag real-time by a few seconds. Use [`/price?asset=X`](#get-single-asset-price) when current price for a specific asset is required.
</Note>
