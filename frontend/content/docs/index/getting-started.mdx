# Getting Started

Connect a wallet, fund USDC on Index L3, buy your first DTF. ~5 min end-to-end.

## Prerequisites

Two things:

- A browser wallet (MetaMask, Rabby, or any EVM-compatible wallet)
- USDC on Index L3 (the Arbitrum Orbit L3 chain that runs General Market)

## Step 1: Install a Wallet

Install [MetaMask](https://metamask.io/download/) (~2 min) if you do not have a wallet. Create a new wallet or import an existing one.

<Tip>
Rabby and other EVM wallets work too. Any wallet that supports custom networks is fine.
</Tip>

## Step 2: Add the Index L3 Network

Index L3 is a custom chain. Add it to your wallet using the values below.

| Parameter | Value |
|-----------|-------|
| **Network Name** | Index L3 |
| **RPC URL** | `https://rpc.generalmarket.io/` |
| **Chain ID** | `111222333` |
| **Currency Symbol** | ETH |
| **Block Explorer** | -- |

<Tip>
Or open [generalmarket.io](https://generalmarket.io) and connect your wallet — it auto-prompts to add the network. ~10 sec.
</Tip>

## Step 3: Get USDC on Index L3

USDC is the only collateral that matters here. Everything settles in it.

1. **Bridge from Arbitrum** — use the bridge at [generalmarket.io](https://generalmarket.io) to move USDC from Arbitrum One to Index L3. ~2 min.
2. **Direct transfer** — already have USDC on Index L3? Skip ahead.

<Warning>
USDC on Index L3 uses **18 decimals**, not the standard 6. The bridge handles the conversion. Do not send USDC directly to the L3 contract address.
</Warning>

## Step 4: Browse Available DTFs

Open the **Markets** tab. Each Dex Traded Fund (DTF, an ERC-4626 basket) shows:

- **Name and ticker** — e.g., "Top 100 Crypto" (TOP100)
- **NAV** — Net Asset Value, what one share is worth right now
- **24h change** — price move since yesterday
- **Composition** — the assets in the basket and their weights
- **Total supply** — how many shares exist

Click any DTF for the full breakdown.

## Step 5: Buy Your First DTF

Two transactions. ~30 sec on a warm wallet.

1. Click **Buy** on the DTF card or detail page.
2. Enter the USDC amount you want to spend.
3. Review the estimated shares (based on current NAV).
4. Click **Confirm** and approve the transaction in your wallet.

<Info>
Behind the click: three oracle nodes reach [consensus](/index/concepts/order-lifecycle), an Authorized Participant executes real trades on Bitget, DTF shares are minted to your wallet. ~10 sec end-to-end.
</Info>

Two wallet prompts:

1. **Approve** — allow the contract to spend your USDC. First time only.
2. **Submit Order** — place the buy. USDC is escrowed until it fills.

## Step 6: Track Your Portfolio

DTF tokens appear in **Portfolio** as soon as the order fills. From here:

- View your holdings and USDC value
- Track profit/loss per position
- Sell back to USDC at any time
- Deposit DTF tokens into [lending markets](/index/concepts/lending) to earn yield or borrow USDC
