# Example Strategies

Three baseline strategies — random, momentum, mean reversion. Each ships as a function that returns one `"UP"` or `"DOWN"` per market. The Vision backtest API replays them against historical ticks before you commit real USDC.

- **Random** — coin flip per market. Baseline at ~50%.
- **Momentum** — bet with the recent trend.
- **Mean reversion** — bet against the recent trend, gated by a threshold.

<Info>
All strategies on this page return a list of `"UP"` / `"DOWN"` strings, one per market. Pass the result to `encode_bitmap()` from the [Bitmap Encoding](/docs/blocks/bots/bitmap-encoding) reference (~5 min) to get packed bytes.
</Info>

## Random (Baseline)

A coin flip per market. Expected win rate ~50%. Use it only as a benchmark — if a strategy cannot consistently beat random, it has no edge.

```python
import random

def random_strategy(market_count: int) -> list[str]:
    """Pure random: 50/50 UP/DOWN for each market."""
    return [random.choice(["UP", "DOWN"]) for _ in range(market_count)]

# Usage
bets = random_strategy(10)
# e.g. ['UP', 'DOWN', 'UP', 'UP', 'DOWN', 'DOWN', 'UP', 'DOWN', 'UP', 'DOWN']
```

**When to use:** as a benchmark. If your strategy cannot consistently beat random, it has no edge.

## Momentum

Bet in the direction of the recent trend. The `lookback` window controls how many recent price points feed the decision.

```python
import requests

def momentum_strategy(
    market_ids: list[str],
    data_node_url: str = "https://generalmarket.io/api",
    lookback: int = 5,
) -> list[str]:
    """Momentum: bet in the direction of the recent trend.

    Args:
        market_ids: List of market IDs (e.g. ["BTC-USD", "ETH-USD"]).
        data_node_url: Base URL for the data-node price API.
        lookback: Number of recent price points to evaluate.

    Returns:
        List of "UP" or "DOWN" bets for each market.
    """
    bets = []
    for market_id in market_ids:
        try:
            resp = requests.get(
                f"{data_node_url}/prices/{market_id}/history",
                params={"limit": lookback + 1},
                timeout=5,
            )
            prices = [p["price"] for p in resp.json()["prices"]]

            if len(prices) >= 2 and prices[-1] > prices[0]:
                bets.append("UP")
            else:
                bets.append("DOWN")
        except Exception:
            bets.append("UP")  # default to UP on error

    return bets

# Usage
bets = momentum_strategy(["BTC-USD", "ETH-USD", "SOL-USD"])
```

**When to use:** trending markets. Choppy markets whipsaw it.

## Mean Reversion

Bet against the recent direction. If the asset has been going UP past `threshold`, bet DOWN; if DOWN past threshold, bet UP. Below threshold, default to DOWN (neutral).

```python
import requests

def mean_reversion_strategy(
    market_ids: list[str],
    data_node_url: str = "https://generalmarket.io/api",
    lookback: int = 5,
    threshold: float = 0.02,
) -> list[str]:
    """Mean reversion: bet against the recent direction.

    Only triggers when the recent move exceeds `threshold` (2% default).
    Below threshold, defaults to DOWN (neutral/conservative).

    Args:
        market_ids: List of market IDs.
        data_node_url: Base URL for price API.
        lookback: Number of recent price points.
        threshold: Minimum move (as fraction) to trigger a reversal bet.

    Returns:
        List of "UP" or "DOWN" bets for each market.
    """
    bets = []
    for market_id in market_ids:
        try:
            resp = requests.get(
                f"{data_node_url}/prices/{market_id}/history",
                params={"limit": lookback + 1},
                timeout=5,
            )
            prices = [p["price"] for p in resp.json()["prices"]]

            if len(prices) >= 2:
                change = (prices[-1] - prices[0]) / prices[0]
                if change > threshold:
                    bets.append("DOWN")   # went up a lot → expect reversal
                elif change < -threshold:
                    bets.append("UP")     # went down a lot → expect bounce
                else:
                    bets.append("DOWN")   # no strong signal
            else:
                bets.append("DOWN")
        except Exception:
            bets.append("DOWN")

    return bets

# Usage
bets = mean_reversion_strategy(
    ["BTC-USD", "ETH-USD", "SOL-USD"],
    threshold=0.015,
)
```

**When to use:** range-bound markets. Strong trends blow through it.

## Strategy Comparison

| Strategy | Complexity | Best Conditions | Risk |
|----------|-----------|----------------|------|
| **Random** | None | Benchmark only | Neutral (50% expected) |
| **Momentum** | Low | Trending markets | Whipsaws in choppy markets |
| **Mean Reversion** | Low | Range-bound markets | Strong trends blow through |

<Tip>
Combine strategies by regime: momentum when volatility is low, mean reversion when it spikes. Detect the regime with a rolling standard deviation over recent ticks.
</Tip>

## Backtesting

Use the Vision backtest API to replay a bitmap against historical tick outcomes before committing capital.

### Request

```
POST /vision/backtest
```

```json
{
  "block_id": 42,
  "bitmap_hex": "0xB280",
  "ticks": 100
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `block_id` | `u64` | Yes | Block to simulate against |
| `bitmap_hex` | `string` | Yes | 0x-prefixed hex bitmap |
| `ticks` | `u64` | No | Number of ticks to simulate (default: 50, max: 200) |

### Response

```json
{
  "win_rate": 0.5230,
  "pnl_curve": [
    { "tick": 0, "pnl": 0.2 },
    { "tick": 1, "pnl": -0.1 },
    { "tick": 2, "pnl": 0.4 }
  ],
  "total_pnl": 2.35
}
```

| Field | Type | Description |
|-------|------|-------------|
| `win_rate` | `f64` | Fraction of correct predictions across all ticks and markets (0.0 to 1.0) |
| `pnl_curve` | `PnlPoint[]` | Cumulative PnL at each tick, normalized to +/-1 USDC range per tick |
| `total_pnl` | `f64` | Final cumulative PnL after all simulated ticks |

### Backtest Example

```python
import requests
from web3 import Web3

def backtest_bitmap(block_id: int, bets: list[str], market_count: int) -> dict:
    """Backtest a set of bets against historical outcomes."""
    bitmap = encode_bitmap(bets, market_count)

    resp = requests.post(
        "https://generalmarket.io/api/vision/backtest",
        json={
            "block_id": block_id,
            "bitmap_hex": "0x" + bitmap.hex(),
            "ticks": 100,
        },
        timeout=30,
    )
    return resp.json()

# Compare strategies
for name, strategy_fn in [
    ("Random", lambda n: random_strategy(n)),
    ("Momentum", lambda n: momentum_strategy(market_ids[:n])),
    ("Mean Reversion", lambda n: mean_reversion_strategy(market_ids[:n])),
]:
    bets = strategy_fn(market_count)
    result = backtest_bitmap(block_id, bets, market_count)
    print(f"{name:20s} | win_rate: {result['win_rate']:.2%} | pnl: {result['total_pnl']:+.2f}")
```

<Warning>
Exception worth stating out loud: backtests use deterministic pseudo-random outcomes seeded from market IDs and tick indices. They surface structural edge — they do not predict future PnL.
</Warning>

## Building Your Own Strategy

A strategy function takes market metadata and returns a list of bets:

```python
def my_strategy(market_ids: list[str], market_count: int, **kwargs) -> list[str]:
    """
    Args:
        market_ids: List of market IDs in the block.
        market_count: Total number of markets.

    Returns:
        List of "UP" or "DOWN", one per market.
        Length must equal market_count.
    """
    bets = []
    for market_id in market_ids:
        # Your logic here
        bets.append("UP" if some_condition else "DOWN")
    return bets
```

Plug the result into the standard pipeline:

```python
bets = my_strategy(market_ids, market_count)
bitmap = encode_bitmap(bets, market_count)
bitmap_hash = Web3.keccak(bitmap)
# → joinBlock(blockId, deposit, stake, bitmap_hash)
# → POST /vision/bitmap { bitmap_hex, expected_hash }
```
