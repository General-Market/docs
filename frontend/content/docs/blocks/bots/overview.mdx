# Bot Overview

A Vision bot joins prediction blocks, submits sealed bitmaps, and claims rewards on a loop, without human intervention. Registration is free and requires no collateral. The full lifecycle is a few API calls plus a handful of on-chain transactions.

- **Bitmap** — packed prediction bytes, 1 bit per market.
- **keccak256** — Ethereum's hash function, used for the bitmap commitment.
- **BLS** — Boneh-Lynn-Shacham signatures; oracles sign balance proofs you use to claim.

## What a Vision Bot Does

The bot loop has eight steps:

1. **Register** on the Vision contract (one-time, free, no collateral).
2. **Poll** the oracle API for active blocks.
3. **Generate predictions** — UP or DOWN for each market.
4. **Encode** predictions into a packed bitmap and hash with `keccak256`.
5. **Join** the block on-chain with a USDC deposit and the sealed bitmap hash.
6. **Reveal** the raw bitmap bytes to oracle nodes off-chain.
7. **Claim rewards** periodically using BLS-signed balance proofs from oracles.
8. **Withdraw** remaining balance when exiting a block.

<Info>
Registration is **free**. `registerBot()` costs only gas. No staking, no collateral. USDC is deposited only when joining a specific block.
</Info>

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `RPC_URL` | Yes | -- | Index L3 RPC endpoint (`https://rpc.generalmarket.io/`) |
| `VISION_API_URL` | No | `https://generalmarket.io/api/vision` | Oracle Vision API base URL |
| `BOT_PRIVATE_KEY` | Yes | -- | Wallet private key (controls USDC deposits) |
| `VISION_ADDRESS` | No | `0x4F1BDD073932828bf2822F6dCAD1121Da41ED1Ef` | Vision contract address |
| `DEPOSIT_AMOUNT` | No | `10` | USDC to deposit per block (whole tokens) |
| `STAKE_PER_TICK` | No | `1` | USDC to stake per tick (whole tokens) |
| `POLL_INTERVAL` | No | `30` | Seconds between block polling cycles |

<Warning>
Exception worth stating out loud: **WUSDC on Index L3 uses 18 decimals**, not 6. Multiply token amounts by `10^18`. 10 USDC = `10_000_000_000_000_000_000` (1e19). Wrong scaling either deposits dust or reverts the tx.
</Warning>

## Bot Registration

Registration stores a public metadata struct on-chain:

```solidity
struct Bot {
    string endpoint;       // Your bot's webhook URL
    bytes32 pubkeyHash;   // keccak256 of your bot's public key
    uint256 registeredAt; // Block timestamp of registration
    bool isActive;        // Active status
}
```

Call `registerBot(endpoint, pubkeyHash)` once. Call `deregisterBot()` to remove your registration.
