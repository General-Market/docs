# Examples

Five runnable repos for building on Blocks. Each one clones, configures, and runs in ~5 min.

- **Python bot** — full lifecycle (register, poll, encode, join, claim)
- **TypeScript bot** — same lifecycle, TS
- **Bitmap encoder** — opinions in, packed bytes out, `keccak256` hash for the seal
- **Momentum strategy** — trend-following
- **Mean reversion strategy** — contrarian

## Quick Start

Every example follows the same four-step setup. ~2 min plus your private key.

1. Clone the repo: `git clone https://github.com/General-Market/examples`
2. Navigate to the example: `cd examples/vision-bot-python`
3. Copy the env file: `cp .env.example .env`
4. Fill in your private key and run

Full walkthrough: [Bot Quickstart](/docs/blocks/bots/quickstart) (~10 min).
