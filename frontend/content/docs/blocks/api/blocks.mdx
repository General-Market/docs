# Blocks & Markets

Two endpoints. One lists active blocks. One lists the markets a block can include. A block is a set of markets that resolve together on a tick schedule.

---

## List Blocks

`GET /vision/blocks`

This endpoint returns all active blocks with live player counts and TVL. Ordered by block ID descending, capped at 100.

<Tabs>
<Tab title="cURL">
```bash
curl https://generalmarket.io/api/vision/blocks
```
</Tab>
<Tab title="Python">
```python
import requests

response = requests.get("https://generalmarket.io/api/vision/blocks")
data = response.json()

for block in data["blocks"]:
    print(f"Block {block['id']}: {block['player_count']} players, TVL: {block['tvl']}")
```
</Tab>
<Tab title="TypeScript">
```typescript
const res = await fetch("https://generalmarket.io/api/vision/blocks");
const { blocks } = await res.json();

for (const block of blocks) {
  console.log(`Block ${block.id}: ${block.player_count} players, TVL: ${block.tvl}`);
}
```
</Tab>
</Tabs>

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | number | Unique block identifier |
| `creator` | string | Ethereum address of the block creator |
| `market_ids` | string[] | List of market identifiers included in the block |
| `market_count` | number | Number of markets in the block |
| `tick_duration` | number | Seconds between tick resolutions |
| `player_count` | number | Current number of active players (from live in-memory state) |
| `tvl` | string | Total value locked across all players, in wei |
| `paused` | boolean | Whether the block is currently paused by oracle consensus |

## List Markets

`GET /vision/markets`

This endpoint returns the oracle-curated whitelist of markets that blocks can include.

<Tabs>
<Tab title="cURL">
```bash
curl https://generalmarket.io/api/vision/markets
```
</Tab>
<Tab title="Python">
```python
import requests

response = requests.get("https://generalmarket.io/api/vision/markets")
markets = response.json()["markets"]

for m in markets:
    print(f"{m['symbol']}: {m['display_name']} ({m['market_id']})")
```
</Tab>
<Tab title="TypeScript">
```typescript
const res = await fetch("https://generalmarket.io/api/vision/markets");
const { markets } = await res.json();

markets.forEach((m: any) =>
  console.log(`${m.symbol}: ${m.display_name} (${m.market_id})`)
);
```
</Tab>
</Tabs>

```json

  "markets": [
    {
      "market_id": "BTC-USD",
      "symbol": "BTC",
      "display_name": "Bitcoin / USD"
    },
    {
      "market_id": "ETH-USD",
      "symbol": "ETH",
      "display_name": "Ethereum / USD"
    },
    {
      "market_id": "SOL-USD",
      "symbol": "SOL",
      "display_name": "Solana / USD"
    }
  ]

```
</Expandable>

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `market_id` | string | Unique market identifier (e.g., `BTC-USD`) |
| `symbol` | string | Short ticker symbol (e.g., `BTC`) |
| `display_name` | string | Human-readable market name (e.g., `Bitcoin / USD`) |
