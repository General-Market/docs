# Vision API

The Vision API is public. No authentication. No rate limits. Use it to list blocks, submit bitmaps, query balances, backtest strategies, and read tick history.

Key terms:

- **Block** — a set of markets that resolve together on a shared tick schedule.
- **Tick** — one resolution event for a block.
- **Bitmap** — a bit-packed array of UP/DOWN predictions, one bit per market.
- **BLS** — Boneh-Lynn-Shacham threshold signatures, used by the oracle quorum to sign withdrawal proofs.

## Architecture

Vision routes split across two proxy targets depending on the data:

```
                            +------------------------------+
                            |   Next.js API Routes         |
                            |   /api/vision/*              |
     +----------+           |                              |
     |          |  HTTPS    |  /blocks ----+              |
     | Browser  +---------->+  /leaderboard |              |
     |          |           |  /bitmap -----+-- fan-out    |
     +----------+           |               |              |
                            |               v              |
                            |     +---------+---------+    |
                            |     | Oracle API        |    |
                            |     | (port 10001)      |    |
                            |     | Block state,      |    |
                            |     | player balances,   |    |
                            |     | bitmap processing  |    |
                            |     +-------------------+    |
                            |                              |
                            |  /snapshot -------+          |
                            |  /snapshot/meta --+          |
                            |                   |          |
                            |                   v          |
                            |     +-------------+-----+    |
                            |     | Data Node         |    |
                            |     | (port 8200)       |    |
                            |     | Market prices,    |    |
                            |     | source health,    |    |
                            |     | asset counts      |    |
                            |     +-------------------+    |
                            +------------------------------+
```

**Bitmap fan-out pattern:**

```
  Browser POSTs bitmap to /api/vision/bitmap (same-origin, no CORS)

                   +-- POST --> Oracle 1 (10001) --> accepted
                   |
  /api/vision/ ----+-- POST --> Oracle 2 (10002) --> accepted
  bitmap           |
                   +-- POST --> Oracle 3 (10003) --> rejected (error)

  Response: { acceptedCount: 2, totalCount: 3, results: [...] }
```

## Base URL

All Vision endpoints are served under:

```
https://generalmarket.io/api/vision
```

Requests are proxied to the oracle node on port 10001, or to the data-node on port 8200 for snapshot data.

## Authentication

None. The Vision API is **public**. Player identity is determined by the Ethereum address passed as a parameter. No keys, no tokens.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | [`/vision/blocks`](/docs/blocks/api/blocks#list-blocks) | List all active blocks |
| `GET` | [`/vision/markets`](/docs/blocks/api/blocks#list-markets) | List supported markets |
| `GET` | [`/vision/block/{id}/state`](/docs/blocks/api/state#get-block-state) | Full state for a single block |
| `POST` | [`/vision/bitmap`](/docs/blocks/api/bitmap#submit-bitmap) | Submit a prediction bitmap (fan-out to all oracles) |
| `GET` | [`/vision/balance/{block_id}/{player}`](/docs/blocks/api/balance#get-player-balance) | Player balance with BLS proof |
| `GET` | [`/vision/block/{id}/history`](/docs/blocks/api/ticks#get-tick-history) | Tick result history for a block |
| `GET` | [`/vision/reveal/{block_id}/{tick_id}`](/docs/blocks/api/ticks#get-revealed-bitmaps) | Revealed bitmaps after tick closes |
| `POST` | [`/vision/backtest`](/docs/blocks/api/ticks#backtest-a-strategy) | Backtest a bitmap strategy |
| `GET` | [`/vision/leaderboard`](/docs/blocks/api/leaderboard#get-leaderboard) | Player rankings by PnL |
| `GET` | [`/vision/snapshot`](/docs/blocks/api/snapshot#get-market-snapshot) | Market price snapshot for all or one source |
| `GET` | [`/vision/snapshot/meta`](/docs/blocks/api/snapshot#get-source-metadata) | Source health, asset counts, sync status |

## Common Patterns

### Wei-Encoded Values

All token amounts (balances, TVL, stake) are returned as **string-encoded wei values** to avoid floating-point precision loss. For L3 USDC (18 decimals), divide by `1e18` to get the human-readable amount.

```python
balance_wei = "5000000000000000000"
balance_usdc = int(balance_wei) / 1e18  # 5.0 USDC (L3 uses 18 decimals)
```

<Warning>
  L3 USDC uses **18 decimals**, not 6. This applies to all Vision balances, TVL, PnL, and block pool values.
</Warning>

### Error Responses

All endpoints return errors in a consistent format:

```json
{
  "error": "Human-readable error message"
}
```

Common HTTP status codes:

| Code | Meaning |
|------|---------|
| `200` | Success |
| `400` | Bad request (invalid parameters, malformed bitmap, etc.) |
| `403` | Forbidden (e.g., reveal window not yet expired) |
| `404` | Resource not found (block or player does not exist) |
| `500` | Internal server error (database failure) |
| `502` | Upstream service (oracle or data-node) unavailable |

### Addresses

Ethereum addresses in responses are formatted as checksummed hex strings with the `0x` prefix (e.g., `0xAbC123...def`).

## Rate Limits

There are currently no rate limits.

## Quick Start

Fetch all active blocks:

<Tabs>
<Tab title="cURL">
```bash
curl https://generalmarket.io/api/vision/blocks
```

<Tab title="Python">
```python
import requests

response = requests.get("https://generalmarket.io/api/vision/blocks")
blocks = response.json()["blocks"]
for block in blocks:
    print(f"Block {block['id']}: {block['market_count']} markets, {block['player_count']} players")
```
