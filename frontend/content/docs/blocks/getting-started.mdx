# Getting Started

Join your first block, place UP/DOWN bets, claim rewards. ~5 min end-to-end.

## Prerequisites

Two things:

- An EVM-compatible wallet (MetaMask, Rabby, or similar) connected to Index L3 (the Arbitrum Orbit L3 chain that runs Vision)
- WUSDC on Index L3 (bridged USDC, 18 decimals — not 6)

<Warning>
Vision runs on **Index L3** (chain ID `111222333`), an Arbitrum Orbit chain. Add it to your wallet: RPC `https://rpc.generalmarket.io/`, chain ID `111222333`, symbol ETH. WUSDC on L3 uses **18 decimals**, not 6.
</Warning>

## Step 1: Browse Active Blocks

Open [generalmarket.io/vision](https://generalmarket.io/vision). Each block shows:

- **Markets** — the assets being tracked (e.g., BTC/USD, ETH/USD, SOL/USD)
- **Tick duration** — how often the block resolves (5 min, 1 hour, 1 day, etc.)
- **Player count** — how many people have joined
- **TVL** — total USDC deposited across all players

Click any block to expand details and see per-market stats.

## Step 2: Understand a Block

A block is a set of markets resolving together on a fixed tick (the resolution interval). Parameters:

| Parameter | Description |
|-----------|-------------|
| **Markets** | The asset pairs players predict on (e.g., BTC/USD, ETH/USD) |
| **Tick duration** | The time interval between resolutions (5 min to 30 days) |
| **Resolution type** | How outcomes are determined — e.g., UP_0 (any upward move), UP_30 (must move +30bps) |
| **Min stake** | Minimum USDC per tick (0.1 USDC) |

<Tip>
Start with a 1-hour or 1-day tick. Short ticks (5 min) burn deposit fast.
</Tip>

## Step 3: Place Your Predictions

For each market in the block, choose **UP** or **DOWN**.

- **UP** — asset price will be higher at end of tick
- **DOWN** — asset price will be lower at end of tick

Predictions pack into a **bitmap** — a binary encoding where each bit is one market (1 = UP, 0 = DOWN). The bitmap hash goes on-chain; the bytes go to oracles after the tick closes. Sealed: nobody sees your bets in advance.

## Step 4: Deposit USDC and Join

Four clicks. ~30 sec on a warm wallet.

1. Set your **deposit amount** — total USDC to allocate to this block.
2. Set your **stake per tick** — USDC wagered per tick. Deposit ÷ stake = number of ticks covered.
3. **Approve** the Vision contract to spend your USDC (first time only).
4. **Confirm** the join transaction. Bitmap hash and deposit go on-chain.

<Info>
Deposit auto-splits across ticks. 10 USDC deposit at 1 USDC/tick = 10 ticks covered. Top up or withdraw at any time.
</Info>

## Step 5: Wait for Tick Resolution

Oracles fetch live prices when the tick closes and resolve each market.

- Price went up + you bet UP → you win that market.
- Price went down + you bet DOWN → you win that market.
- Winners on each market split losers' stakes proportionally, minus 0.05% fee on profits.

Balance updates after each tick. Check the block detail page for per-tick results and running PnL.

## Step 6: Claim Rewards

Withdraw via a BLS-signed balance proof. ~1 transaction.

1. Open **My Positions** on the Vision page.
2. Click **Withdraw** on the block you want to exit.
3. The oracle network generates a BLS-signed balance proof. Three oracles sign; 2-of-3 quorum needed.
4. Confirm the withdrawal transaction. USDC lands in your wallet immediately.

<Info>
Partial claims are allowed. You do not need to exit the whole block.
</Info>

## Programmatic Access

Vision exposes a REST API for bots and scripts. Two common operations below.

### Fetch Active Blocks

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -s https://generalmarket.io/api/vision/blocks | jq .
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    resp = requests.get("https://generalmarket.io/api/vision/blocks")
    blocks = resp.json()

    for block in blocks:
        print(f"Block {block['id']}: {block['market_count']} markets, "
              f"{block['player_count']} players, TVL: {block['tvl']}")
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    const res = await fetch("https://generalmarket.io/api/vision/blocks");
    const blocks = await res.json();

    for (const block of blocks) {
      console.log(
        `Block ${block.id}: ${block.market_count} markets, ` +
        `${block.player_count} players, TVL: ${block.tvl}`
      );
    }
    ```
  </Tab>
</Tabs>

### Check Your Balance

<Tabs>
  <Tab title="cURL">
    ```bash
    BLOCK_ID=1
    PLAYER=0xYourAddress
    curl -s "https://generalmarket.io/api/vision/balance/$BLOCK_ID/$PLAYER" | jq .
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    block_id = 1
    player = "0xYourAddress"
    resp = requests.get(
        f"https://generalmarket.io/api/vision/balance/{block_id}/{player}"
    )
    balance = resp.json()
    print(f"Balance: {balance['balance']} (WUSDC raw, 18 decimals)")
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    const blockId = 1;
    const player = "0xYourAddress";
    const res = await fetch(
      `https://generalmarket.io/api/vision/balance/${blockId}/${player}`
    );
    const balance = await res.json();
    console.log(`Balance: ${balance.balance} (WUSDC raw, 18 decimals)`);
    ```
  </Tab>
</Tabs>
