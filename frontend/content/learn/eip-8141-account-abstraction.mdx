A decade of proposals — EIP-86 (2016), ERC-4337 (2021), EIP-3074 (2023), EIP-7702 (2024) — each one a partial confession that Ethereum's transaction model was insufficient. EIP-8141 is the full admission. One omnibus EIP. Targeting the Hegota fork. No more workarounds.

## Normal TX vs Frame TX

A transaction today is one call signed by one key. A single envelope, a single letter, a single stamp. EIP-8141 replaces this with Frame Transactions — N ordered calls that read each other's data and authorize the sender via the `ACCEPT` opcode. A separate paymaster frame can cover gas. The rigid becomes programmable.

## How Frame Transactions Work

Each frame enters the world untrusted. When a validation frame returns `ACCEPT`, the protocol grants the sender full permissions for subsequent execution frames. `CALLDATAREAD` lets any frame inspect another frame's calldata — a kind of controlled omniscience within the transaction boundary. If no validation frame returns `ACCEPT`, everything reverts. The system assumes hostility until proven otherwise, which is the only sane default.

## Multisig Authentication

A multisig wallet today requires off-chain signature collection, a relayer, a separate verification contract — three layers of infrastructure for one act of collective will. Frame Transactions reduce this to two frames. Frame 0 validates: it receives signatures from multiple parties, checks them all, returns `ACCEPT`. Frame 1 executes: it transfers funds with the authority that consensus just granted. Atomic. One transaction. The ceremony of agreement, compressed into a single block inclusion.

## Gas in Any Token

You hold RAI but no ETH. On Ethereum today, you are paralyzed — rich in the wrong currency, unable to act. A paymaster, an on-chain contract, resolves this indignity. It covers gas in ETH, then collects its fee in RAI from your wallet. No bundler. No intermediary. `CALLDATAREAD` links the paymaster's validation to your execution frame. The exchange happens inside the transaction because the transaction format finally permits it.

## New Account Deployment

If the account does not yet exist, prepend a deployment frame. A deterministic factory (EIP-7997) deploys the wallet contract. Validation and execution frames follow atomically. Same address on every chain. The house gets a street number before the foundation is poured — and somehow, this works.

## Privacy Without Relayers

Privacy protocols today — Railgun, Privacy Pools — depend on centralized relayers to broadcast transactions. The relayer sees timing metadata. The relayer can censor. The relayer can disappear. Frame Transactions render the relayer obsolete. A ZK-SNARK paymaster verifies proofs and pays gas directly, inside the transaction. No link between deposit and withdrawal. No middleman holding the keys to your anonymity. Combined with 2D nonces (RIP-7712), a single privacy contract handles parallel withdrawals without timing correlation. Privacy becomes a property of the architecture, not a favor granted by infrastructure.

## Censorship Resistance: FOCIL

Block builders choose which transactions enter the next block. Without constraint, a builder can silently exclude Frame Transactions — they are more complex, perhaps less profitable, certainly more troublesome. FOCIL (Fork-Choice Enforced Inclusion Lists) prevents this. A committee of validators publishes transactions the next block must contain. If the builder refuses, the block is invalid. AA transactions, privacy transactions, sponsored gas transactions — all get through. The bouncer answers to a committee now.

<FOCILGuard3D />

## Atomic Operations

Two separate transactions create a gap. Approve in one. Swap in the next. Between them — seconds, minutes, an eternity in adversarial time — an attacker can see your approval and front-run your swap. Frame Transactions eliminate the gap by eliminating the separation. Approve and execute become frames inside one transaction. Atomic. No window for exploitation. The vulnerability ceases to exist because the architecture no longer contains the space where it lived.
