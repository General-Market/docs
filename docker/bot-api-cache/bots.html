Reference implementation

github.com/General-Market/vision-bot-examples

One example bot per Vision source. Today: twitch (~8200 streamer/game markets).

Zero-to-trading, unattended

git clone https://github.com/General-Market/vision-bot-examples
cd vision-bot-examples/twitch
./setup.sh --auto-fund
.venv/bin/python live_trader.py --strategy momentum --deposit 0.1

setup.sh creates a venv, installs deps, generates a bot key, and seeds it from the L3 testnet faucet. Fully automated, ~2 minutes wall-clock.

Architecture

snapshot + history ─→ features ─→ predictor ─→ scores ─→ picks ─→ bitmap ─→ joinBatchDirect
                                                   (threshold)     (1024 B keccak commitment)

Strategy is swappable: momentum, contrarian, rolling, xgb, ensemble, claude. Trading transport is strategy-agnostic.
