# remotion-video-producer-sidecar

This folder stores persistent memory for the **ShotForge** Expert agent.

## Purpose
Persistent knowledge base for translating creative direction files into Remotion compositions. Stores schema mappings, production protocols, and accumulated session learnings.

## Files
- `memories.md`: Session learnings — schema refinements, deviation logs, component patterns
- `instructions.md`: Production protocols — project paths, architecture patterns, standards
- `schema-mappings.md`: Full direction.json → ShotDef mapping tables (enums, camera, VFX, SFX)

## Runtime Access
After BMAD installation, this folder will be accessible at:
`{project-root}/_bmad/_memory/remotion-video-producer-sidecar/`
