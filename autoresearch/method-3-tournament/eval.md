# Method 3: Comparative Tournament Evaluation

## Process

For each iteration:
1. Present the evaluator with VERSION N-1 and VERSION N side by side
2. Labels are randomized ("Script A" / "Script B") — the evaluator does not know which is newer
3. The evaluator answers 5 questions:

### Questions

**Q1: ATTENTION** — Which script would make a VC stop scrolling and watch to the end?
- Answer: A or B
- 1-sentence justification

**Q2: MEMORABILITY** — Which script would a VC quote to their partner at dinner?
- Answer: A or B
- 1-sentence justification

**Q3: CLARITY** — Which script makes the product clearer to someone who has never heard of it?
- Answer: A or B
- 1-sentence justification

**Q4: EMOTION** — Which script creates a stronger emotional response (any emotion: awe, humor, curiosity, FOMO)?
- Answer: A or B
- 1-sentence justification

**Q5: OVERALL** — If you could only show one to investors, which one?
- Answer: A or B
- 1-sentence justification

## Scoring

Win rate = questions won by newer version / 5 × 100

- Win rate > 60%: KEEP the new version
- Win rate = 40-60%: TIE — keep the new version (bias toward progress)
- Win rate < 40%: REVERT to previous version

## Anti-Gaming Rules
- Labels are randomized per evaluation
- The evaluator must justify every choice
- If all 5 answers are the same, the evaluator must explicitly confirm this is not default bias
- The agent modifying the script CANNOT see or modify this file
