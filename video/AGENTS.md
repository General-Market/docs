## Agents

- Maximum **5 concurrent sub-agents** at any time. Do not exceed this limit.

## Git

This project is version-controlled. **Always commit changes** to avoid losing work.

- Before making significant edits, check `git status` and commit any pending changes first
- After completing a task or making working changes, commit with a descriptive message
- Use granular commits (one per logical change) rather than one large commit at the end
- Studio server runs on **port 3333**: `npx remotion studio --port 3333`

## YouTube video descriptions

When you need to write a YouTube video description, read `.claude/rules/ytb_video_description.md` first — it's the reference template for structure, chapters, resource links, and tone.
