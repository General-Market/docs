## Design Context

### Users
Institutional investors and sophisticated traders interacting with decentralized index products (ITPs) and AI prediction markets (Vision). They expect data density, precision, and the visual language of Bloomberg/iShares — not startup playfulness. Many users are AI agents (bots) interacting programmatically, but the human-facing UI must convey trust, control, and technical competence.

### Brand Personality
Institutional. Precise. Understated. The interface communicates through restraint — what it omits matters as much as what it shows. Warmth arrives by accident, through the fact that someone bothered to be exact.

### Aesthetic Direction
- **Visual tone**: BlackRock/iShares institutional. Black, white, zinc grays, semantic green/red. No gradients, no decorative elements, no purple.
- **References**: Bloomberg Terminal (data density), iShares fund pages (typography hierarchy), Vanguard (restraint)
- **Anti-references**: Anything with purple gradients, floating decorative blobs, emoji as icons, rainbow color palettes, or "Get Started" hero sections.
- **Theme**: Light mode primary. Dark terminal mode (`bg-terminal: #18181B`) for data-dense views (ITPs, markets).

### Design Principles
1. **Data first, decoration never.** Every pixel serves information. If an element doesn't help the user decide, it doesn't exist.
2. **The design system is the law.** Use tokens (`color-up`, `text-muted`, `border-light`, `rounded-card`, `shadow-card`). Never bypass with raw Tailwind values.
3. **Asymmetry over symmetry.** Not everything deserves equal visual weight. PnL matters more than "Bets Set." Top 3 ranks matter more than rank 47.
4. **Typography is the design.** Inter for interface, JetBrains Mono for data. Hierarchy through weight and size, not color or decoration.
5. **Institutional trust through consistency.** Same border radius, same shadows, same spacing, same color semantics everywhere. The user should never notice the design — only the data.

### Design Tokens
- **Colors**: `text-primary (#1A1A1A)`, `text-secondary (#555)`, `text-muted (#999)`, `color-up (#16A34A)`, `color-down (#DC2626)`, `color-warning (#D97706)`, `color-info (#2563EB)`, `brand (#00A36C)`, `terminal (#18181B)`
- **Surfaces**: `bg-page (#FFF)`, `bg-surface (#F5F5F5)`, `bg-card (#FFF)`, `bg-muted (#F4F4F5)`
- **Borders**: `border-light (#E0E0E0)`, `border-medium (#D4D4D8)`, `border-strong (#000)`
- **Shadows**: `shadow-card (0 1px 2px rgba(0,0,0,0.04))`, `shadow-modal (0 25px 50px rgba(0,0,0,0.20))`
- **Radius**: `rounded-card (6px)`, `rounded-md` for buttons/inputs, never `rounded-xl` or `rounded-2xl`
- **Fonts**: Inter (sans), JetBrains Mono (mono)
- **Labels**: 10-11px, font-semibold, uppercase, tracking-[0.08-0.12em], text-text-muted
- **Section dividers**: 3px solid black (`.section-divider`)
- **SectionBar**: Black bar with white uppercase label (use sparingly — max 2-3 per page)

### Component Patterns
- **EmptyState**: ASCII art icons (`○ ○ ○`, `┌─────┐`, `#1 ───`), not SVG circles or emoji
- **StatusBadge**: Typographic indicators (`○ ● ◐ ✓ ✗`), not colored dots
- **Cards**: `rounded-card` (6px), `border border-border-light`, `shadow-card`. Interactive: `hover:border-black`
- **Tables**: 3px black header border, `hover:bg-surface` rows
- **Buttons**: `rounded-md`, primary = `bg-zinc-900 text-white`, buy = `bg-color-up`, sell = `bg-color-down`
- **Loading**: Custom `skeleton` class with brand-colored pulse, not raw `animate-pulse bg-gray-200`
- **Charts (Recharts)**: Tick fill `#999999`, tooltip border `#E0E0E0`, stroke `#000`, gradient from black
