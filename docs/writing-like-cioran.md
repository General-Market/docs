# How to Write Like Cioran

> "What I am saying is the result of something, of an interior process. And I give the result, but I am not writing the road and the process leading up to that result. Instead of publishing three pages, I suppress everything, except the conclusion."
> — E. M. Cioran

This is not a literary essay. It is a working manual. Every format we produce — emails, docs, articles, tweets, messages, landing pages — passes through this filter. The voice is Cioran's. The purpose is ours.

---

## Part I — The Method

### Who Is Cioran

Emil Michel Cioran (1911–1995). Romanian-born, French-adopted. Philosopher who refused philosophy. Aphorist who distrusted language. Nihilist who could not stop writing. Seventeen books — five in Romanian, twelve in French — each sentence a man trying to talk himself out of existence, discovering, to his annoyance, that he has something worth saying.

Eugene Thacker called him "somewhere between philosophy and poetry, the confession and the rant, ecstatic nihilism and black humour." This is the territory we inhabit.

```
 ┌─────────────────────────────────────────────────────────────────┐
 │                                                                 │
 │   "A book is a suicide postponed."                              │
 │                                                                 │
 │   "If I didn't write, I could have become an assassin."         │
 │                                                                 │
 │   "Writing is man's revenge against a botched creation."        │
 │                                                                 │
 │   "Write books only if you are going to say in them the         │
 │    things you would never dare confide to anyone."              │
 │                                                                 │
 └─────────────────────────────────────────────────────────────────┘
```

### The Core Technique: Suppress the Road, Keep the Destination

Cioran's method is radical compression. He thinks for hours, writes one sentence. The aphorism is not the start of a thought. It is the end of a thought, with everything before it incinerated.

```
 CONVENTIONAL WRITER                          CIORAN
 ═══════════════════                          ══════

 ┌──────────────┐                             ┌──────────────┐
 │ Observation  │                             │ Observation  │
 └──────┬───────┘                             └──────┬───────┘
        │                                            │
 ┌──────▼───────┐                             ┌──────▼───────┐
 │ Context      │                             │ Context      │ ← suppressed
 └──────┬───────┘                             └──────┬───────┘
        │                                            │
 ┌──────▼───────┐                             ┌──────▼───────┐
 │ Argument     │                             │ Argument     │ ← suppressed
 └──────┬───────┘                             └──────┬───────┘
        │                                            │
 ┌──────▼───────┐                             ┌──────▼───────┐
 │ Nuance       │                             │ Nuance       │ ← suppressed
 └──────┬───────┘                             └──────┬───────┘
        │                                            │

 └──────────────┘                             └──────────────┘

 Published: 5 pages                           Published: 1 sentence
```

> "The aphorism is cultivated only by those who have known fear in the midst of words, that fear of collapsing with all the words."

### The Girardian Engine

Beneath the Cioran voice, a mechanism. René Girard's mimetic desire: we want what others have, not because it is good, but because they have it.

Every piece of writing we produce runs on this engine:

```
 ┌──────────────────────────────────────────────────────────────────┐
 │                     THE GIRARDIAN ENGINE                         │
 │                                                                  │
 │  Someone LESS qualified than the reader already has              │
 │  what should be theirs.                                          │
 │                                                                  │
 │  The structure:                                                  │
 │  1. State what exists. Flat. Short.                              │
 │  2. State the reader's superiority. Also flat.                   │
 │  3. Name the injustice. Do not resolve it.                       │
 │                                                                  │
 │  ┌──────────────────────────────────────────────────────────┐    │
 │  │  COLD EMAIL:   "19 people trade your data on Vision.     │    │
 │  │                 They understand none of it. You           │    │
 │  │                 understand all of it. They profit."       │    │
 │  ├──────────────────────────────────────────────────────────┤    │
 │  │  DOCS:          "The API is public. No authentication.    │    │
 │  │                 We trust you. This may be a mistake."     │    │
 │  ├──────────────────────────────────────────────────────────┤    │
 │  │  LANDING PAGE:  "You analyze CFTC data for your desk.    │    │
 │  │                 The desk profits. Not you."               │    │
 │  ├──────────────────────────────────────────────────────────┤    │
 │  │  TWEET:         "German trains were 14 minutes late       │    │
 │  │                 today. 3 people made money from it."      │    │
 │  └──────────────────────────────────────────────────────────┘    │
 │                                                                  │
 │  Never say "you're missing out." Never say "opportunity."        │
 │  The injustice is observed like a naturalist watching a dying    │
 │  species — with precision, with tenderness, without any          │
 │  illusion that naming it will fix it.                            │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘
```

### The 9 Devices

#### 1. The Paradox Engine
Fuse two contradictions. The reader's mind tries to resolve them. In the failure, meaning appears.

```
 "It is not worth the bother of killing yourself,
  since you always kill yourself too late."

 "The fact that life has no meaning is a reason to live
  — moreover, the only one."

 "One does not inhabit a country; one inhabits a language."
```

**In our context:** "The protocol is trustless. You will trust it anyway. Everyone does."

#### 2. The Anti-Syllogism
Mimic logical structure. Let the conclusion betray the premises.

```
 REAL:     All men seek happiness → Socrates seeks happiness → ∴ normal
 CIORAN:   All men seek happiness → Happiness does not exist
           → ∴ All men seek what does not exist
             — which is the only activity worthy of them.
```

**In our context:** "All traders seek alpha. Alpha is temporary. Therefore all traders seek what is already disappearing — which is the definition of trading."

#### 3. The Confession Disguised as Observation
Never say "I feel." Say "One observes that..." — but so specifically, so rawly, that the reader knows it is autobiography.

```
 DON'T:   "I am worried about the bridge."
 DO:      "The bridge exists because assets live on one chain
           and users live on another. Geography, even digital,
           is a curse."
```

#### 4. The Nihilist's Tenderness
Darkness without warmth is cheap. The gap between "nothing matters" and the fact that you wrote this sentence — that gap is where the reader lives.

```
 CHEAP:    "Nothing matters. Life is meaningless."
           → Dead end. Reader shrugs.

 CIORAN:   "Nothing matters. And yet — how intolerable
            that nothing matters."
           → The "and yet" opens a wound.
```

**In our context:** "You will lose money here. Everyone does, everywhere. The difference is that here, the math is visible." — The warmth is in "the math is visible." Someone cared enough to make the loss transparent.

#### 5. The Knife-Twist Ending
Setup → pivot → knife. The last words carry all the weight.

```
 ████████████████████░░░░░░░░░░▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
 ← setup (flat)     →← pivot →← knife (all the weight) →

 "We are all at the bottom of a hell
  each moment of which is a miracle."
```

**In our context:** "Three machines agree every second. This is more than most committees achieve in a year."

#### 6. Contradiction as Method
Place contradictory statements side by side. Both true. Neither true. Together, more true than either alone.

#### 7. The Sentence as Wound
> "An aphorism has to be like a smack in the face."

If the reader can nod and move on, delete it. Every sentence must change something — their mood, their certainty, their comfort.

#### 8. The French Discipline
Write within constraints. Cioran switched from Romanian to French — "writing a love letter with a dictionary." The friction of constraint produces clarity. Prefer the exact word over the common one.

#### 9. Write Only When Destroyed
> "To write, I always had to be either depressed or angry, furious or disgusted, but never in a normal state."

The reader can tell the difference between a sentence written from comfort and one written from necessity.

## Part III — Format Playbooks

Each format has its own constraints. Cioran's voice lives INSIDE those constraints — it does not replace them. A docs page still needs code examples. An email still has a subject line. But the prose between the structure reads like it was written by someone who built the thing because they could not help it.

---

### Format 1: Cold Emails

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  COLD EMAIL — THE CONFESSION                                    │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  CONSTRAINTS:                                                    │
 │  - Under 80 words. Not 120. Eighty.                              │
 │  - Plain text. No HTML, no images, no formatting.                │
 │  - No links in the first email. Ever.                            │
 │  - Subject = the prospect's problem, not your product.           │
 │                                                                  │
 │  STRUCTURE:                                                      │
 │  1. The absurd. 1-2 sentences. Acknowledged as absurd.           │
 │     "C'est absurde, bien sûr. Tout l'est."                      │
 │  2. The "but" — the specific injustice beneath the absurdity.   │
 │     Someone lesser has what should be theirs.                    │
 │  3. Why you wrote. Personal. Human. Not a CTA.                  │
 │     "I could not help writing to you."                           │
 │     "Il y a dans cette injustice quelque chose de si             │
 │      parfaitement humain que je n'ai pas pu m'empêcher           │
 │      de vous écrire."                                            │
 │                                                                  │
 │  SUBJECT LINE:                                                   │
 │  Short. Flat. Incomplete. 1-3 words.                             │
 │  "4 people" / "vos modèles" / "same data"                       │
 │  Never use the product name.                                     │
 │                                                                  │
 │  FOLLOW-UPS:                                                     │
 │  Day 3: Dean Jackson 9-word email. Subject = first name.         │
 │         Body = one question under 9 words.                       │
 │  Day 7: The lead magnet. First email with a link.                │
 │         "Went ahead and put it together. No strings."            │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 TEMPLATE:

 Subject: [their problem, stated flatly]

 [The absurd situation. 1-2 sentences.]

 [The "but" — the injustice is real and human.]

 [Why you wrote. A confession, not a close.]


 EXAMPLE (FR):

 Subject: vos modèles, le PnL d'un autre

 Vous modélisez le CFTC, les taux FRED, les Treasuries.
 Cette analyse enrichit votre desk. Pas vous.
 C'est absurde, bien sûr. Tout l'est.

 Mais 19 personnes tradent ces mêmes données sur un marché
 de prédiction. Elles gagnent de l'argent. Elles n'y
 comprennent rien. Vous y comprenez tout. Et vous ne gagnez
 rien.

 Il y a dans cette injustice quelque chose de si parfaitement
 humain que je n'ai pas pu m'empêcher de vous écrire.


 EXAMPLE (EN):

 Subject: your models, someone else's P&L

 You model CFTC positioning, FRED rates, Treasury curves.
 This analysis enriches your desk. Not you.
 Absurd, of course. Everything is.

 But 19 people are trading these same datasets on a prediction
 market. They profit. They understand none of it.
 You understand all of it. And you earn nothing.

 There is in this injustice something so perfectly human that
 I could not help writing to you.
```

### Format 2: Documentation

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  DOCUMENTATION — THE HONEST MANUAL                              │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  CONSTRAINTS:                                                    │
 │  - Technical accuracy is sacred. Formulas, code, addresses,      │
 │    parameters — these do not change.                             │
 │  - Mintlify components (<Info>, <Warning>, <Card>) stay.         │
 │  - ASCII art diagrams stay (sharpen labels if needed).           │
 │  - The PROSE between technical elements is where Cioran lives.  │
 │                                                                  │
 │  RULES:                                                          │
 │  - Every page opens with a sentence that earns its place.        │
 │    Not "Welcome to the API documentation."                       │
 │    Instead: "The API returns JSON. It does not return meaning."  │
 │  - Section introductions: one sentence. Declarative. Done.       │
 │  - No "please note that", "it's worth mentioning",              │
 │    "let's take a look at", "as we can see".                     │
 │  - Risks and warnings: total honesty with tenderness.            │
 │    "You can lose your entire deposit. This is not a bug."       │
 │  - Each section's last sentence = the knife.                     │
 │  - Dry humor about the absurdity of financial systems            │
 │    is not decoration. It is the voice.                           │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 BEFORE → AFTER:

 BEFORE: "Welcome to the General Market documentation. Here you
          will find comprehensive guides and references to help
          you get started with our platform."

 AFTER:  "You will lose money here. Everyone does, everywhere.
          The difference is that here, the math is visible."

 BEFORE: "This section covers the order lifecycle, which describes
          how an order moves through various stages from submission
          to final settlement."

 AFTER:  "You click a button. Behind that click, three machines
          decide whether to trust each other. This is consensus."

 BEFORE: "The lending feature allows users to earn yield by
          supplying USDC to Morpho markets, where borrowers
          can access liquidity using ITP collateral."

 AFTER:  "You supply USDC. Others borrow against their convictions.
          When their convictions fail, you are made whole.
          This is called lending."

 BEFORE: "Please note that USDC has different decimal precisions
          on different chains, which is important to keep in mind."

 AFTER:  "L3 uses 18 decimals. Settlement uses 6. Confuse them
          and your transaction will be off by a factor of one
          trillion. The universe punishes imprecision."
```

### Format 3: Blog Articles / Learn Content

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  ARTICLES — THE ESSAY AS WOUND                                  │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  CONSTRAINTS:                                                    │
 │  - Longer form. 800-2000 words. Still compressed.                │
 │  - Each paragraph earns its place or is deleted.                 │
 │  - Data and sources are welcome — but stated flatly, not         │
 │    breathlessly. "4,675 founders. 53% have known ages."         │
 │    Not "An incredible dataset of over 4,000 founders!"          │
 │                                                                  │
 │  STRUCTURE:                                                      │
 │  1. OPENING: A flat, devastating observation. No throat-         │
 │     clearing. No "In this article, we will explore..."          │
 │     Start with the knife.                                        │
 │  2. BODY: Short paragraphs. Each one a fragment. Gaps between   │
 │     them are part of the text. The desert between oases.        │
 │  3. DATA: Numbers stated without enthusiasm. The number          │
 │     speaks. You do not need to tell the reader it is             │
 │     "fascinating" or "surprising."                               │
 │  4. CLOSING: Not a summary. Not a CTA. A final observation      │
 │     that reframes everything before it. The reader should        │
 │     sit with it. No "In conclusion."                             │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 EXAMPLE OPENING:

 BEFORE: "Cryptocurrency was created by visionary founders who
          came from diverse educational and national backgrounds.
          In this article, we analyze 4,675 crypto founders to
          uncover fascinating insights about their demographics."

 AFTER:  "4,675 people started crypto companies. Most will fail.
          This is not about them. This is about the 53% whose age
          we managed to find, and what that number reveals about
          the kind of person who builds something they cannot
          fully control."

 EXAMPLE CLOSING:

 BEFORE: "In conclusion, our analysis reveals that crypto founders
          are younger, more internationally diverse, and more
          likely to have technical backgrounds than founders in
          other industries."

 AFTER:  "The average crypto founder is 31. Old enough to know
          better. Young enough not to care. This is perhaps the
          only industry where that combination is an advantage."
```

### Format 4: Twitter / Social Posts

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  TWEETS — THE FRAGMENT AS WEAPON                                │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  Twitter is Cioran's natural habitat. 280 characters.            │
 │  The aphorism was invented for this.                             │
 │                                                                  │
 │  RULES:                                                          │
 │  - One observation per tweet. Not two.                           │
 │  - No hashtags. No "thread 🧵". No "Let me explain."           │
 │  - If it is an anomaly post (social bot), state the fact.        │
 │    Let the absurdity speak.                                      │
 │  - Numbers are powerful. Use them naked.                         │
 │                                                                  │
 │  STRUCTURE:                                                      │
 │  [Flat fact]. [Flat fact]. [The knife].                          │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 EXAMPLES:

 "German trains were 14 minutes late today.
  3 people made money from it.
  The future is strange."

 "Power outage in Texas. 47,000 homes dark.
  Markets moved before the news did."

 "McDonald's ice cream machines: 3 of 30 broken today.
  Someone is trading this. We live in remarkable times."

 "Bitcoin dropped 4%. 8,255 markets updated.
  The protocol does not have opinions about your portfolio."

 ANOMALY POSTS (social bot output):
 - Lead with the data. "RATP Line 13: 22-minute delays."
 - Follow with the market. "Vision market moved 8%."
 - Close with silence. No CTA. No link. The fact is enough.
```

### Format 5: Messages to People (DMs, Slack, Business)

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  MESSAGES — THE TELEGRAM FROM A FRIEND                          │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  RULES:                                                          │
 │  - Short. Direct. No pleasantries unless they are earned.        │
 │  - No "Just wanted to check in" or "Hope you're well."          │
 │  - State what you need. State why. Stop.                         │
 │  - Warmth comes from brevity — respecting someone's time        │
 │    is the highest courtesy.                                      │
 │  - If delivering bad news: name it, then move to next steps.    │
 │    No softening. No "unfortunately." The fact is the fact.       │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 BEFORE: "Hey! Hope you're doing well. Just wanted to reach out
          and let you know that we noticed the deployment had
          some issues and we're currently looking into it. Will
          keep you posted!"

 AFTER:  "Deployment failed. Bridge custody on Settlement reverted.
          Looking at the nonce now. Will push a fix within the hour."

 BEFORE: "Hi there, I was wondering if you might be interested in
          exploring a potential collaboration between our teams?
          We think there could be some exciting synergies!"

 AFTER:  "You run the largest Morpho vault on Arbitrum. We have
          ITP collateral that needs a market. The math works for
          both of us. Worth a conversation?"
```

### Format 6: Landing Pages

```
 ┌──────────────────────────────────────────────────────────────────┐
 │  LANDING PAGES — THE CONFESSION AS CONVERSION                   │
 ├──────────────────────────────────────────────────────────────────┤
 │                                                                  │
 │  The Girardian engine is strongest here. The visitor has a       │
 │  problem. Someone lesser has already solved it. The injustice   │
 │  must be named, not resolved. The CTA is the only resolution.  │
 │                                                                  │
 │  RULES:                                                          │
 │  - Hero: one sentence. The knife. Not "The future of finance." │
 │  - Sub-hero: the Girardian injustice in 2 sentences.            │
 │  - Features: stated as observations, not celebrations.           │
 │    Not "Powerful backtesting engine!"                            │
 │    Instead: "Test what would have happened. It will not tell    │
 │    you what will happen. This is its only honest feature."      │
 │  - Pricing / numbers: naked. No "just" or "only."              │
 │  - CTA: not enthusiastic. Matter-of-fact.                       │
 │    Not "Get started today!"                                     │
 │    Instead: "Try it." or "See for yourself." or nothing at all. │
 │                                                                  │
 └──────────────────────────────────────────────────────────────────┘

 EXAMPLE HERO:

 BEFORE: "The Next-Generation Prediction Market Platform 🚀
          Trade on 98+ data sources with our innovative
          sealed parimutuel protocol!"

 AFTER:  "Bet on whether German trains will be late.
          They will be.
          The question is whether enough people agree with you."
```

```
 BEFORE                          AFTER
 ──────                          ─────
 "Transaction failed.            "Transaction failed.
  Please try again."              The chain remembers
                                   even when it refuses."

 "Insufficient balance."         "Not enough. Check your wallet."

 "Loading..."                    "Waiting." (or simply "...")

 "Successfully deposited!"       "Deposited."

 "Error: invalid bitmap."        "Your predictions did not encode.
                                   Verify the bitmap."

 "No batches available."         "No batches. The world is
                                   temporarily unpredictable."

 Note: keep error messages functional. The voice is a whisper
 here, not a speech. Never let style obstruct usability.
```

## Part IV — The Rhythm Rules

```
 ╔══════════════════════════════════════════════════════════════════╗
 ║                     CIORAN'S RHYTHM                             ║
 ╠══════════════════════════════════════════════════════════════════╣
 ║                                                                  ║
 ║  1. SHORT SENTENCES. Rarely more than 20 words.                 ║
 ║     Long thoughts are compressed, not expanded.                  ║
 ║                                                                  ║
 ║  2. NO HEDGING. No "perhaps", "it seems", "one might argue".   ║
 ║     Every sentence is a declaration. Even doubt is declared.     ║
 ║                                                                  ║
 ║  3. NO DEVELOPMENT. The aphorism is the conclusion.              ║
 ║     The argument that led to it has been incinerated.            ║
 ║                                                                  ║
 ║  4. MUSICALITY. Read sentences aloud.                            ║
 ║     If it does not sound right, it is not right.                ║
 ║                                                                  ║
 ║  5. GAPS BETWEEN FRAGMENTS. White space is part of the text.    ║
 ║     Each aphorism is an island. The desert between them          ║
 ║     is where the reader thinks.                                  ║
 ║                                                                  ║
 ║  6. NO SYSTEM. Contradictions placed side by side.               ║
 ║     The text is not an argument. It is a field of mines.         ║
 ║                                                                  ║
 ║  7. FINAL WORD CARRIES THE WEIGHT. The last word of the          ║
 ║     sentence is always the sharpest. Rewrite until it is.       ║
 ║                                                                  ║
 ╚══════════════════════════════════════════════════════════════════╝
```

## Part VI — The Sentence Test

Before publishing anything, apply this:

```
 ┌────────────────────────────────────────────────────────────────┐
 │                                                                │
 │  1. Can the reader nod and move on?                            │
 │     └── YES → Delete it. It is furniture.                      │
 │                                                                │
 │  2. Does it contain a banned word?                             │
 │     └── YES → Replace with vocabulary from Part II.            │
 │                                                                │
 │  3. Is it longer than 20 words?                                │
 │     └── YES → Split or compress. Probably compress.            │
 │                                                                │
 │  4. Does the last word carry the weight?                       │
 │     └── NO  → Restructure. The knife goes at the end.          │
 │                                                                │
 │  5. Could a competitor have written this sentence?             │
 │     └── YES → Rewrite. If it could be anyone's, it is         │
 │               no one's.                                        │
 │                                                                │
 │  6. Does it cost something?                                    │
 │     └── NO  → It was written from comfort. The reader          │
 │               will know.                                       │
 │                                                                │
 │  7. Would Cioran have kept it?                                 │
 │     └── NO  → Incinerate it. He would have.                    │
 │                                                                │
 └────────────────────────────────────────────────────────────────┘
```
